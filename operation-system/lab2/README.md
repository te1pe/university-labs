# Лабораторная 2 — Системные вызовы

**Курс:** Операционные системы, 01.09.2025–31.12.2025

## Задание

1. Эксперименты со `strace`:
   - запустить hello world из лабораторной 1 под `strace`, разобраться, какие
     системные вызовы вызваны и чем обусловлено их количество; определить, какой
     вызов используется для вывода строки, что он принимает и возвращает;
   - использовать этот сискол вместо `printf()`, убедиться, что он есть в выводе `strace`;
   - написать свою обёртку над сисколом через `syscall()` из libc, проверить `strace`;
   - запустить под `strace` команду `wget kernel.org`, получить статистику
     использования системных вызовов порождённым процессом.
2. Разобраться, как устроена функция `syscall()`; написать код, печатающий
   hello world без её использования.
3. Разобраться с `ptrace(2)` и написать программу, которая породит процесс
   и выведет все системные вызовы дочернего процесса.

## Файлы

| Файл | Что это |
| --- | --- |
| `hello.c` | исходная программа для запуска под `strace` |
| `hello_write.c` | вывод напрямую системным вызовом `write(1, ...)` |
| `hello_syscall.c` | своя обёртка `my_write()` через `syscall(SYS_write, ...)` |

> Программа-трейсер на `ptrace(2)` (пункт 3) в работе не реализована.

## Сборка и запуск

```bash
gcc hello.c -o hello
gcc hello_write.c -o hello_write
gcc hello_syscall.c -o hello_syscall

strace ./hello           # в выводе видно write(1, "Hello world\n", 12)
strace ./hello_write     # тот же write, но без обвязки stdio
strace ./hello_syscall   # syscall() приводит к тому же write

strace -c wget kernel.org   # сводная статистика по вызовам
```

## Что показывает работа

`printf` — это функция libc, а не системный вызов: она форматирует строку в
буфер stdio и в итоге вызывает `write(2)`. Поэтому в `strace` виден именно
`write(1, "Hello world\n", 12)`. `hello_write.c` обращается к `write` напрямую,
минуя буферизацию stdio, `hello_syscall.c` — через `syscall(SYS_write, …)`,
то есть по номеру вызова; во всех трёх случаях ядру приходит одно и то же.
Остальные вызовы в выводе `strace` — работа динамического загрузчика:
`execve`, `mmap`, `openat` библиотек, `arch_prctl`.
