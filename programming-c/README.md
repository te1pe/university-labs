# Программирование на C

**Период:** 01.09.2024-31.05.25

**Язык:** C

Базовый курс процедурного программирования. Ручное управление памятью, указатели
и адресная арифметика, работа с файлами и потоками ввода-вывода, структуры данных
без готовых библиотек, разбор алгоритмов и оценка их сложности.

## Чему учит курс

- Модель памяти C: стек, куча, сегменты; `malloc`/`free` и типовые утечки
- Указатели, указатели на указатели, массивы как указатели, `void*`
- Структуры, объединения, битовые операции и упаковка данных
- Файловый и потоковый ввод-вывод, буферизация
- Раздельная компиляция, заголовочные файлы, `make`
