# Лабораторная 6 — Низкоуровневая работа с периферийными устройствами

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

Ознакомиться с началами низкоуровневого программирования периферийных устройств
на примере получения информации о доступных USB-устройствах через библиотеку libusb.

## Задание

1. Реализовать программу, получающую список всех подключённых USB-устройств.
   Для каждого напечатать класс, идентификатор производителя и идентификатор изделия.
2. Изучить состав и характеристики обнаруженных устройств.
3. Дополнить программу печатью серийного номера устройства, используя
   `libusb_open`, `libusb_close`, `libusb_get_string_descriptor_ascii`
   для поля `iSerialNumber` дескриптора.

## Реализация

`PrintDev` читает дескриптор устройства и печатает класс, VID и PID в
шестнадцатеричном виде. `PrintSerialNumber` открывает устройство и читает
ASCII-строку серийного номера; устройства без серийного номера обрабатываются
отдельной веткой.

## Файлы

| Файл | Что это |
| --- | --- |
| `usb_list.cpp` | перечисление USB-устройств и чтение серийных номеров |
| `report.docx` | отчёт с описанием обнаруженных устройств |

```bash
g++ usb_list.cpp -o usb_list $(pkg-config --cflags --libs libusb-1.0)
./usb_list
```
