# Лабораторная 5 — Высокоуровневая работа с периферийными устройствами

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

Ознакомиться с программированием периферийных устройств на примере ввода данных
с web-камеры с использованием библиотеки OpenCV.

## Задание

1. Реализовать программу на OpenCV, получающую поток видеоданных с камеры и
   выводящую его на экран.
2. Выполнить произвольное преобразование изображения.
3. Измерить количество кадров в секунду. Оценить долю времени, затрачиваемого
   процессором на ввод, преобразование и показ видеоданных.

## Реализация

Кадр за кадром замеряются три интервала через `std::clock()`: чтение с камеры,
попиксельная обработка, вывод на экран. По завершении печатается FPS и доля
каждой стадии в процентах от общего времени.

## Файлы

| Файл | Что это |
| --- | --- |
| `camera.cpp` | захват с камеры, преобразование, замер долей времени |
| `report.docx` | отчёт с результатами замеров |

```bash
g++ camera.cpp -o camera $(pkg-config --cflags --libs opencv4)
./camera        # Esc — выход
```
