# Лабораторная 8 — Влияние кэш-памяти на время обработки массивов

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

1. Исследование зависимости времени доступа к данным в памяти от их объёма.
2. Исследование зависимости времени доступа от порядка обхода.

## Задание

1. Написать программу, многократно обходящую массив заданного размера тремя способами.
2. Для каждого размера и способа обхода измерить среднее время доступа к элементу
   в тактах процессора, построить графики.
3. По графикам определить размеры кэш-памяти разных уровней, сопоставить с реальными
   характеристиками процессора; определить, при каких размерах случайный обход
   становится дороже прямого и обратного, и объяснить причину.

## Реализация

Массив заполняется индексами так, что обход превращается в цепочку переходов
`next = mas[next]` — это не даёт процессору спекулятивно подгружать данные наперёд.
Три способа заполнения: `Straight` (прямой), `Reverse` (обратный), `Random`
(случайная перестановка через `std::set` посещённых). Время измеряется инструкцией
`rdtsc` в тактах. Размер массива растёт от 1 КБ до 32 МБ с переменным шагом
(`ReloadSize`) — мелкий шаг на размерах кэшей, крупный дальше.
