# Лабораторная 10 — Определение степени ассоциативности кэша L1i

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

Экспериментальное определение степени ассоциативности кэша инструкций (L1i).

## Задание

Написать программу, выполняющую обход памяти в соответствии с заданием, измерить
среднее время и определить степень ассоциативности L1i, сравнив с реальными
характеристиками процессора.

## Реализация

Отличие от лабораторной 9: исследуется кэш **инструкций**, поэтому конфликтующие
обращения создаются не данными, а самим кодом. Определён набор из 16 функций
`func0`…`func15`, написанных ассемблерной вставкой:

- объявлены через `extern "C"` с атрибутом `noinline`, чтобы компилятор не выполнил
  инлайнинг и не изменил их структуру;
- размещены в одной секции `.text`, каждая начинается с `.p2align 12` —
  выравнивание по границе 4 КБ;
- тело — цепочка `nop`, чтобы функция занимала предсказуемый объём кэш-линий.

Программа вызывает первые `blocks_num` функций по кругу и замеряет среднее время
одного вызова. Пока число блоков не превышает ассоциативность L1i, все они лежат
в кэше; дальше начинаются промахи и время растёт.
