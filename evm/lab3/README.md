# Лабораторная 3 — Введение в архитектуру x86/x86-64

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

1. Знакомство с программной архитектурой x86/x86-64.
2. Анализ ассемблерного листинга программы для архитектуры x86/x86-64.

## Задание

Изучить программную архитектуру x86/x86-64: набор регистров, арифметико-логические
команды, способы адресации памяти и передачи управления, работу со стеком, вызов
подпрограмм и передачу параметров, арифметический сопроцессор, векторные расширения.

Для программы из лабораторной 1 сгенерировать ассемблерные листинги под x86 и x86-64
с разными уровнями оптимизации, сопоставить команды Си с машинными командами,
определить размещение переменных, описать оптимизационные преобразования компилятора.

## Разбор в отчёте

- сопоставление конструкций C++ с машинными командами построчно
- размещение переменных: `esi` = n, `ebx` = i при `-O3` вместо стека
- `lea` для вычисления `2*i+1`, `xor eax, eax` вместо `mov eax, 0`
- инлайнинг: прямая модификация структуры `cout` вместо вызова манипуляторов
- сравнение 32- и 64-битных листингов: передача параметров через регистры
  (`rdi`, `rsi`) против стека, использование SIMD (`pshufd`, `movq`)
