# Лабораторная 2 — Изучение оптимизирующего компилятора

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

1. Изучение основных функций оптимизирующего компилятора, примеров оптимизирующих
   преобразований и уровней оптимизации.
2. Получение базовых навыков работы с компилятором GCC.
3. Исследование влияния оптимизационных настроек GCC на время исполнения программы.

## Задание

Реализовать сортировку пузырьком массива случайных чисел длины N. Подобрать N так,
чтобы время работы было 30–60 секунд. Скомпилировать с уровнями `-O0`, `-O1`, `-O2`,
`-O3`, `-Os`, `-Ofast`, `-Og` под x86 и для каждого варианта измерить время работы
при нескольких значениях N.

## Выводы из отчёта

- `-O0` даёт худший результат: все оптимизации отключены ради читаемости при отладке
- сборка без флага быстрее `-O0` — компилятор по умолчанию применяет базовые оптимизации
- `-O1`, `-O2`, `-O3`, `-Ofast` дают основной прирост, разница между ними невелика
- `-Os` близок к `-O1`/`-O2`, но проигрывает на больших объёмах данных: цель — размер файла
- `-Og` медленнее прочих: приоритет у пригодности к отладке
