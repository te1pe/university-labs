# Лабораторная 1 — Определение времени работы прикладных программ

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

1. Изучение методики измерения времени работы подпрограммы.
2. Изучение приёмов повышения точности измерения времени работы.
3. Изучение способов измерения времени работы подпрограммы.
4. Измерение времени работы подпрограммы в прикладной программе.

## Задание

Реализовать вычисление числа π разложением в ряд Грегори — Лейбница по N первых
членов ряда. Проверить правильность на нескольких тестовых наборах. Подобрать N
так, чтобы время работы было порядка 15 секунд. Определить время работы
подпрограммы с относительной погрешностью не более 1%.

## Результат

- N = 390 000 000 даёт время работы ≈ 15 с
- Относительная погрешность измерения: 10 мс / 15 000 мс = 0,07%
- Измерение утилитой `time`: разобраны составляющие `real`, `user`, `sys`
