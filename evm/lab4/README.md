# Лабораторная 4 — Введение в архитектуру ARM

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

1. Знакомство с программной архитектурой ARM.
2. Анализ ассемблерного листинга программы для архитектуры ARM.

## Задание

Изучить основы программной архитектуры ARM. Для программы из лабораторной 1
сгенерировать ассемблерные листинги под ARM с разными уровнями оптимизации,
сопоставить команды Си с машинными, определить размещение переменных, описать
оптимизационные преобразования и продемонстрировать ключевые особенности ARM.

## Разбор в отчёте

Сравнение неоптимизированного и оптимизированного листингов для 32-битной ARM:

- **размещение переменных:** без оптимизации `sum` и `i` лежат на стеке
  (`[r7, #16]`, `[r7, #12]`); с оптимизацией `sum` — в VFP-регистре `d8`,
  счётчики — в `r4`/`r5`
- **организация цикла:** `lsls` + `adds` для `2*i+1` против явного счётчика
  знаменателя `add r5, r5, #2`
- **вызов pow:** через шаблонную обёртку `__gnu_cxx::__promote_2` против
  прямого `bl pow` с аргументами в VFP-регистрах
- **вывод:** вызовы `operator<<` и `setprecision` против прямой записи
  во внутренние поля `std::cout` — быстрее, но хрупко
- **пролог/эпилог:** frame pointer `r7` и `sub sp, sp, #24` против
  `push`/`pop` без frame pointer
