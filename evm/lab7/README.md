# Лабораторная 7 — Векторизация вычислений

**Курс:** ЭВМ, 01.09.2025–31.12.2025

## Цель

1. Изучение SIMD-расширений архитектуры x86/x86-64.
2. Изучение способов использования SIMD-расширений в программах на языке Си.
3. Получение навыков использования SIMD-расширений.

## Задание

Написать три варианта программы, реализующей алгоритм из задания:

1. без ручной векторизации,
2. с ручной векторизацией (ассемблерная вставка, встроенные функции компилятора
   или расширение GCC),
3. с матричными операциями через оптимизированную библиотеку BLAS.

Элементы матриц — `float`. Каждый вариант оптимизировать по скорости. Сравнить
время работы трёх вариантов при N = 2048, M = 10.

## Файлы

| Файл | Что это |
| --- | --- |
| `Main.cpp` | точка входа, принимает N и M аргументами командной строки |
| `Matrix.h` | интерфейс класса матрицы |
| `Matrix.cpp` | вариант 1 — без ручной векторизации |
| `MatrixVector.cpp` | вариант 2 — ручная векторизация через SSE-интринсики (`__m128`, `_mm_add_ps`, `_mm_mul_ps`) |
| `MatrixBLAS.cpp` | вариант 3 — умножение через `cblas_sgemm` из BLAS |
| `report.docx` | отчёт с замерами трёх вариантов |

Все три варианта реализуют один и тот же интерфейс `Matrix.h` и различаются
только реализацией операторов — собирается ровно один из них:

```bash
# вариант 1 — без векторизации
g++ -O2 Main.cpp Matrix.cpp -o matrix

# вариант 2 — SSE-интринсики
g++ -O2 -msse Main.cpp MatrixVector.cpp -o matrix_sse

# вариант 3 — BLAS
g++ -O2 Main.cpp MatrixBLAS.cpp -o matrix_blas -lopenblas

./matrix 2048 10
```

Вычисляется обратная матрица разложением в ряд: `A⁻¹ ≈ (I + R + R² + … + Rᴹ) · B`,
где `B = Aᵀ / (‖A‖₁ · ‖A‖∞)`, `R = I − BA`. Основная нагрузка — умножение матриц,
поэтому именно оно и векторизуется.
