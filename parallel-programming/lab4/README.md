# Лабораторная 4 — Метод Якоби в трёхмерной области на MPI

**Курс:** Параллельное программирование, 01.01.2026–31.05.2026

## Задача

Параллельная реализация метода Якоби для трёхмерной области. Область разрезается
между MPI-процессами по одному из измерений; на каждой итерации процессы
обмениваются граничными слоями с соседями, после чего пересчитывают внутренние узлы.

Ключевой приём: обмен границами совмещается с вычислением внутренних узлов через
неблокирующие операции, чтобы коммуникации шли параллельно счёту.

## Файлы

| Файл | Что это |
| --- | --- |
| `mpi_jacobi.c` | метод Якоби с разрезанием 3D-области |
| `report.docx` | отчёт с замерами и графиками ускорения |

```bash
mpicc -O2 mpi_jacobi.c -o jacobi -lm
mpirun -np 4 ./jacobi
```
