# Лабораторная 1 — Решение СЛАУ методом простой итерации на MPI

**Курс:** Параллельное программирование, 01.01.2026–31.05.2026

## Задача

Решить систему линейных алгебраических уравнений итерационным методом с
распараллеливанием через MPI. Реализованы два варианта декомпозиции:

- **Вариант 1** — векторы `x` и `b` дублируются в каждом MPI-процессе,
  матрица `A` разрезается по строкам между процессами.
- **Вариант 2** — векторы `x` и `b` разрезаются между процессами аналогично матрице `A`.

## Параметры

`N = 5000`, `EPS = 1E-7`, `TAU = 1E-5`

## Файлы

| Файл | Что это |
| --- | --- |
| `mpi_slae_1.c` | вариант 1 — дублирование векторов |
| `mpi_slae_2.c` | вариант 2 — разрезание векторов |
| `report.docx` | отчёт с замерами времени и ускорения |

```bash
mpicc -O2 mpi_slae_1.c -o slae1 -lm
mpirun -np 4 ./slae1
```
