# Лабораторная 5 — Многопоточные приложения, POSIX Threads

**Курс:** Параллельное программирование, 01.01.2026–31.05.2026

## Задача

Программирование многопоточных приложений на POSIX Threads в связке с MPI.
Задача — балансировка нагрузки между процессами: работа распределена неравномерно,
и освободившиеся процессы должны забирать задачи у загруженных.

Реализованы два варианта:

| Вариант | Файл | Что делает |
| --- | --- | --- |
| Без балансировки | `nonbalanced.c` | каждый процесс выполняет свою порцию задач до конца; общее время определяется самым загруженным |
| С балансировкой | `balanced.c` | отдельный поток-приёмник обслуживает запросы на задачи, освободившиеся процессы запрашивают работу у соседей |

Второй вариант и есть суть работы: pthread нужен, чтобы процесс мог одновременно
считать свои задачи и отвечать на запросы других — без отдельного потока запрос
пришлось бы ждать до конца счёта.

## Файлы

| Файл | Что это |
| --- | --- |
| `nonbalanced.c` | вариант без балансировки |
| `balanced.c` | вариант с балансировкой через pthread |
| `report.docx` | отчёт со сравнением времён и дисбаланса |

```bash
mpicc -O2 balanced.c -o balanced -lpthread -lm
mpirun -np 4 ./balanced
```

> Требуется MPI с поддержкой `MPI_THREAD_MULTIPLE`.
