# Лабораторная 2 — Решение СЛАУ методом простой итерации на OpenMP

**Курс:** Параллельное программирование, 01.01.2026–31.05.2026

## Задача

Та же система линейных уравнений, что в лабораторной 1, но распараллеленная
средствами OpenMP. Реализованы три варианта, различающиеся организацией
параллельных областей и распределением итераций:

| Вариант | Файл | Подход |
| --- | --- | --- |
| 1 | `omp_parallel_for.c` | `#pragma omp parallel for` на каждом цикле — параллельная область создаётся заново |
| 2 | `omp_single_region.c` | одна параллельная область, внутри `#pragma omp for` — накладные расходы на создание потоков платятся один раз |
| 3 | `omp_schedule_runtime.c` | `schedule(runtime)` — стратегия распределения итераций задаётся переменной `OMP_SCHEDULE` без перекомпиляции |

## Файлы

| Файл | Что это |
| --- | --- |
| `omp_parallel_for.c` | вариант 1 |
| `omp_single_region.c` | вариант 2 |
| `omp_schedule_runtime.c` | вариант 3 |
| `report.docx` | отчёт со сравнением вариантов и замерами |

```bash
gcc -O2 -fopenmp omp_single_region.c -o slae -lm
OMP_NUM_THREADS=8 ./slae
OMP_SCHEDULE="dynamic,100" ./slae   # для варианта 3
```
