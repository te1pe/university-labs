# Лабораторная 3 — Умножение матриц на двумерной решётке MPI

**Курс:** Параллельное программирование, 01.01.2026–31.05.2026

## Задача

Параллельное умножение матрицы на матрицу с декомпозицией на двумерную решётку
MPI-процессов. Процессы объединяются в декартову топологию, каждый отвечает за
свой блок результирующей матрицы; полосы исходных матриц рассылаются по строкам
и столбцам решётки.

## Файлы

| Файл | Что это |
| --- | --- |
| `matrix_multiplication.c` | умножение матриц на 2D-решётке процессов |
| `report.docx` | отчёт с замерами при разных конфигурациях решётки |

```bash
mpicc -O2 matrix_multiplication.c -o matmul -lm
mpirun -np 8 ./matmul
```
