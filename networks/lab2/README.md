# Лабораторная 2 — VLAN и статическая маршрутизация

**Курс:** Компьютерные сети, 01.09.2025–31.12.2025

## Задание

Собрать сеть из четырёх сетей — A, B, C и D:

- сети **A** и **B** создаются с помощью VLAN на одном коммутаторе;
- маршрутизатор **R1** связывает сети A и B между собой и с сетью **C**;
- маршрутизатор **R2** связывает сеть C с сетью **D**;
- в сети **D** конечные устройства подключаются по беспроводной связи
  (точка доступа WiFi), в A и B — витой парой.

В сетях A, B и D подключить хотя бы по одному конечному устройству.

Настроить DHCP на маршрутизаторах или отдельных серверах, чтобы устройства в
сетях A, B и D получали IP-адреса автоматически.

Устройства из каждой сети должны иметь возможность отправлять и получать пакеты
устройствам из остальных сетей.

## Что показывает работа

VLAN делит один физический коммутатор на несколько независимых широковещательных
доменов: устройства из A не видят широковещательные кадры B, хотя воткнуты в одну
железку. Связать их можно только через маршрутизатор — отсюда схема router-on-a-stick
с транковым портом до R1 и подынтерфейсами на каждый VLAN.

Сети C и D за R2 доступны не автоматически: без статических маршрутов R1 не знает,
куда слать пакеты в D, а R2 — как вернуть ответ в A и B. Достаточно забыть один
из двух маршрутов — и трафик пойдёт в одну сторону, но не вернётся; ping будет
молчать, хотя пакет доходит.
