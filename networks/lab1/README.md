# Лабораторная 1 — Коммутация и ARP

**Курс:** Компьютерные сети, 01.09.2025–31.12.2025

## Задание

Собрать сеть из четырёх конечных устройств, используя два коммутатора
(по два устройства на каждом коммутаторе).

Настроить интерфейсы статически так, чтобы все устройства находились в одном
адресном пространстве (IPv4). Проверить, что все конечные устройства могут
посылать друг другу ICMP-пакеты.

1. Проследить за прохождением ICMP-пакетов по сети.
2. Проследить за прохождением ARP-пакетов.
3. Проследить за заполнением таблиц коммутации на коммутаторах.
4. Проследить за заполнением ARP-таблиц на конечных устройствах.

## Что показывает работа

Первый ping не уходит сразу: устройство знает IP получателя, но не знает его
MAC-адрес, поэтому сначала шлёт широковещательный ARP-запрос «у кого такой IP».
Коммутатор рассылает его во все порты кроме входного, владелец адреса отвечает
уникастом, и только после этого уходит ICMP. Поэтому в выводе ping первый пакет
часто теряется по таймауту.

Таблица коммутации заполняется по адресу **источника**: получив кадр, коммутатор
запоминает, за каким портом живёт его MAC. Пока таблица пуста, кадры с неизвестным
получателем рассылаются во все порты (flood); после первого обмена — направляются
адресно.
