# Лабораторная 3 — Анализ DNS и HTTP трафика в Wireshark

**Курс:** Компьютерные сети, 01.09.2025–31.12.2025

## Задание

Изучить процесс взаимодействия клиента и сервера при запросе веб-страницы,
проанализировать DNS и HTTP трафик с помощью Wireshark.

1. Запустить Wireshark и начать захват трафика на интерфейсе с интернет-подключением.
2. Открыть в браузере веб-сайт по протоколу HTTP (без TLS).
3. Проанализировать DNS-запросы и ответы.
4. Проанализировать HTTP-запросы и ответы.
5. Проанализировать установление TCP-соединения (three-way handshake).

Измерить время, затраченное на эти взаимодействия.

Разобраться, что означают основные поля в заголовках (MAC-адреса для Ethernet,
IP-адреса для IP, порты для TCP и так далее) и что за значения в них видны.

Повторить шаги с сайтом, использующим TLS, и сравнить наблюдаемые взаимодействия.

> **N.B.** Если DNS-трафик не наблюдается — проверить, не использует ли браузер
> DNS over HTTPS. В этом случае взять другой браузер, консольный клиент
> (`curl`, `wget`) или временно отключить DoH.

## Фильтры Wireshark

```
dns                          только DNS
http                         только HTTP
tcp.flags.syn == 1           начало установления соединения
tcp.stream eq 0              один TCP-поток целиком
tls.handshake.type == 1      Client Hello
```
