# Лабораторная 0б — Частотный словарь слов (CSV)

**Период:** 01.09.2025-31.12.2025

**Язык:** C++

Программа принимает текстовый файл, считает частоту каждого слова и выводит
CSV-отчёт, упорядоченный по убыванию частоты. Разделителями считаются все
символы, кроме букв и цифр.

## Формат вывода

| Колонка | Содержимое |
| --- | --- |
| 1 | Слово |
| 2 | Частота (количество вхождений) |
| 3 | Частота в процентах от общего числа слов |

## Реализация

Класс `CSV` инкапсулирует весь разбор:

- `std::map<std::string, int> wordCount` — словарь частот, упорядочен по ключу
- `Isword()` — классификация символа: буква/цифра против разделителя
- `PointDefis()` — нормализация слова перед учётом
- `ComparePairs()` — компаратор для сортировки по убыванию частоты
- Буфер чтения на 5 МБ — файл не читается посимвольно

## Файлы

```
main.cpp    точка входа, разбор аргументов
csv.h       интерфейс класса CSV

```
