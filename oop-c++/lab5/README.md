# Лабораторная 5 — Игра «Жизнь»

**Период:** 01.09.2025 — 31.12.2025

**Язык:** C++ · **Сборка:** CMake · **Тесты:** GoogleTest

Клеточный автомат Конвея с загрузкой вселенной из файла формата Life 1.06,
настраиваемым правилом перехода и тремя режимами запуска. Поле замкнуто в тор:
правый край склеен с левым, верхний с нижним.

## Режимы запуска

| Команда | Режим |
| --- | --- |
| `./life` | встроенная вселенная, интерактивный режим |
| `./life universes/glider.life` | вселенная из файла, интерактивный режим |
| `./life --input in.life --output out.life --iterations 20` | оффлайн-расчёт |

Короткие ключи оффлайн-режима: `-I` (вход), `-o` (выход), `-i` (итерации).

## Команды в интерактивном режиме

| Команда | Действие |
| --- | --- |
| `tick <n>`, `t <n>` | рассчитать n итераций и показать каждый кадр (по умолчанию 1) |
| `dump <filename>` | сохранить вселенную в файл Life 1.06 |
| `help` | справка о командах |
| `exit` | выход |

## Архитектура

```
LifeModel — механика, о вводе и выводе не знает
├── Field           упакованное поле, тороидальные координаты
├── computeIteration()  один шаг автомата
└── getAliveCells()     состояние для сохранения

LifeView — печать, состояния не хранит
├── printFrame()    кадр с именем, правилом и номером итерации
├── printHelp()
└── printError() / printWarning()

LifeController — разбор файла, цикл команд, оффлайн-режим
```

## Хранение поля

Клетки упакованы по 8 штук в байт: строка занимает `(side + 7) / 8` байт, поле
20×20 — 60 байт вместо 400. Клетка `(row, column)` живёт в байте
`row * bytesInRow + column / 8` на позиции `column % 8`.

Замкнутость поля спрятана внутрь `Field`: приватный `wrap()` приводит любую
координату к диапазону `[0, side)`, поэтому `getState(-1, -1)` — это правый
нижний угол, а подсчёт соседей на краю не требует отдельной ветки.

Итерация считается в два буфера: `current` читается, `next` заполняется, в
конце они меняются местами через `std::swap`. Новое поколение не может повлиять
само на себя во время расчёта.

## Файлы

```
main.cpp            разбор аргументов командной строки
lifem.h/.cpp        LifeModel и Field: поле, правила, шаг автомата
lifev.h/.cpp        LifeView: кадр, справка, сообщения
lifec.h/.cpp        LifeController: чтение и запись Life 1.06, цикл команд
test.cpp            модульные тесты механики
universes/          примеры вселенных с разными правилами
```

## Сборка и запуск

```bash
cmake -B build && cmake --build build
./build/bin/life universes/glider.life
./build/bin/run_tests
```
