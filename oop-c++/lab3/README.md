# Лабораторная 3 — Flappy Bird (SFML)

**Период:** 01.09.2025 - 31.12.2025

**Язык:** C++ **Графика:** SFML **Сборка:** CMake

Клон Flappy Bird: птица падает под действием гравитации, по нажатию
подпрыгивает. Столкновение — конец игры,
рестарт по клавише.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Space` или ЛКМ | прыжок |
| `R` | перезапуск после проигрыша |

## Архитектура

Две независимые сущности, обе управляют своим состоянием и рисуют себя сами;
`main.cpp` содержит только игровой цикл и связывает их через проверку
пересечения прямоугольников.

**`Bird`** — физика падения и прыжка:

**`Towers`** — генерация и движение препятствий. Внутренняя структура
`Column` хранит верхний и нижний прямоугольник и умеет сама определять,
ушла ли она за экран и пересекается ли с птицей.

Все сеттеры ограничивают значение снизу, чтобы игра не ломалась от
некорректного параметра.

## Файлы

```
main.cpp        игровой цикл, обработка событий
Bird.hpp/.cpp   птица: физика, отрисовка, коллизии
Tower.hpp/.cpp  столбы: генерация, движение, коллизии
assets/bird.png 
```

## Сборка и запуск

```bash
cmake -B build && cmake --build build
./build/bin/flappy_min
```

Требуется SFML (компоненты Graphics, Window, System).
