# Лабораторная 2 — Битовый массив

**Период:** 01.09.2025 — 31.12.2025

**Язык:** C++ · **Сборка:** CMake · **Тесты:** GoogleTest

Контейнер, компактно хранящий последовательность бит, — аналог `std::bitset`,
но с размером, известным только во время выполнения. Биты упакованы по 64 штуки
в машинное слово, поэтому массив из 10 000 бит занимает 1 250 байт, а не 10 000.

## Хранение

Бит с индексом `i` лежит в `blocks[i / 64]` на позиции `i % 64`. Младшему биту
блока соответствует меньший индекс — благодаря этому сдвиг массива совпадает со
сдвигом многословного числа и делается словами, а не побитово.

**Хвост последнего блока** — главная тонкость реализации. `bit_count` не обязан
делиться на 64, лишние биты обязаны оставаться нулями: иначе `count()`, `any()`
и сравнение двух массивов начнут учитывать мусор. Приватный `trim_tail()`
вызывается после каждой операции над блоками и гасит хвост — это единственное
место, где живёт маска, поэтому ошибиться можно только один раз.

## Реализация

| Операция | Как сделана | Сложность |
| --- | --- | --- |
| `set(n)`, `operator[]` | маска `1 << (n % 64)` по одному блоку | O(1) |
| `&=`, `\|=`, `^=` | поблочно, с проверкой совпадения размеров | O(n / 64) |
| `<<=`, `>>=` | сдвиг на `n / 64` блоков плюс `n % 64` бит со склейкой соседей | O(n / 64) |
| `count()` | алгоритм Кернигана: `block &= block - 1` гасит младшую единицу | O(k), k — число единиц |
| `~` | инверсия блоков и `trim_tail()` | O(n / 64) |

**Обработка ошибок.** Отрицательный размер в конструкторе и `resize()` —
`std::invalid_argument`. Индекс за границей в `set()`, `reset()`, `operator[]` —
`std::out_of_range`. Битовые операции над массивами разного размера —
`std::invalid_argument`: обрезать или дополнять молча опаснее, чем сообщить о
несоответствии, поэтому выбран отказ, а не приведение к общему размеру.

**Класс `reference`** нужен, чтобы `array[i] = true` работал как присваивание:
неконстантный `operator[]` возвращает прокси, который помнит владельца и индекс
и переадресует запись в `set()`. Константная версия возвращает обычный `bool`.
