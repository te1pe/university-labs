# Лабораторная 1 — Кэш LRU и LFU через общий интерфейс

**Период:** 01.09.2025 — 31.12.2025

**Язык:** C++ · **Сборка:** CMake · **Тесты:** GoogleTest

Две стратегии вытеснения кэша за одним абстрактным интерфейсом. Кэш
подключается к вычислению чисел Фибоначчи, которое обращается к нему через
базовый класс и не знает, какая стратегия работает под ним.

## Архитектура

```
Icache (абстрактный интерфейс)
├── get(int key)
├── put(int key, int data)
└── operator[](int key)
     │
     ├── LRU  — вытеснение по давности обращения
     └── LFU  — вытеснение по частоте обращений
```

`fibonachi(int n, Icache& cache)` принимает ссылку на интерфейс — это и есть
точка полиморфизма: подмена стратегии не требует изменения кода вычисления.

## Реализация

**LRU** — `std::list<std::pair<int,int>>` хранит порядок использования,
`std::unordered_map<int, list::iterator>` даёт доступ к узлу за O(1).
Обращение переносит узел в голову списка, вытесняется хвост.

**LFU** — `std::unordered_map<int, std::list<Node>> freq_lists`: отдельный
список на каждое значение частоты, плюс `min_freq` для поиска кандидата на
вытеснение без обхода. Приватный `touch()` переносит узел между списками
частот. Все операции — O(1).
